# Standards & reference texts

These are **deliberately not in the repository** — they are copyrighted works that cannot be
redistributed. They are listed here so the sources behind this board's rules are on the record, and
kept locally outside the repo tree.

| Work | What this project uses it for |
|---|---|
| **IPC-2221** — Generic Standard on Printed Board Design | Conductor sizing and clearance/creepage numbers; the trace widths in `docs/Hard_Rules_Layout_RevA.md` were checked against it |
| **Ritchey, *Right the First Time: A Practical Handbook on High-Speed PCB and System Design*, Vol. 1** (Speeding Edge) | The return-current and stackup reasoning behind this board's 4-layer strategy — see `docs/Routing_Guide_RevA_4Layer.md` |

Vendor datasheets, which *are* freely redistributable, live in
[`../datasheets/`](../datasheets/) and are indexed there.
